ANDROID BETA — PHYSICAL DEVICE TESTERS WANTED

Re:Awaken Android Beta 1 (1.0.0-beta.1)
This is a PUBLIC BETA, not stable or fully hardware-validated Android support.
Physical-device compatibility is what this beta is intended to test.

Proven in Android 11 emulator:
* APK validation
* Non-root APK installation
* Non-root OBB placement
* SHA256 verification
* Game launch
* Dark Road offline gameplay
* Union χ Theater offline playback
* Progress persistence

The non-root install was proved on a separate fresh, never-rooted emulator.
Gameplay/theater/persistence were proved in the earlier Android 11 emulator
validation; those runtime tests initially used root solely for development OBB
placement. The beta's installer never requests or uses root. These two evidence
sets do not establish compatibility with every physical device or Android version.

NOT YET PROVEN ON PHYSICAL ANDROID HARDWARE.
Android 8+ is the companion's declared range, conditional on actual access and
ABI/API checks. Android 11 is tested; other Android versions/OEM firmware are
untested. AYN Thor and other Android handheld reports are especially useful.
Only the primary Android user is supported. Controller mapping is not included.

Requirements:
* Windows 10/11 x64 PC with .NET Framework 4.8
* Android device supporting the APK's ARM64 or ARMv7 native libraries
* USB data cable and USB debugging enabled
* User-owned compatible KHUX + Dark Road 5.0.1 WW XAPK
* Internet on the PC for legitimate runtime/ADB tooling, with SDK terms accepted
* Local staging space of about 2.3 GB plus the XAPK/tools, and about 3 GB free
  space on Android. This does not include all future gameplay/save needs.

Start:
Extract ReAwaken-Android-Beta-1-Windows-x64.zip to a writable folder.
Open ReAwaken-Android-Beta.exe. Connect/unlock Android. Enable Developer Options
by tapping Build number seven times (usually Settings > About device, sometimes
under Software information). Enable USB debugging in Developer Options and
accept the computer authorization prompt. Select your own XAPK, review SDK terms,
then Install on Android. A verified official Node runtime and its complete
upstream license are bundled; the launcher obtains verified official ADB.

The flow validates the original APK plus main.76 and patch.87 OBBs, installs,
places both OBBs, verifies SHA256 from device storage, and launches the game.
No game APK/XAPK/OBB/content is supplied, downloaded or re-signed by Re:Awaken.
Compatibility validation is pinned to the known validated original files; a
different/repacked XAPK is refused for review. No APK/OBB patches are needed for
the tested offline paths. The optional Google Play Games prompt can be cancelled.

If direct ADB OBB access is restricted, Re:Awaken uses its own signed installer
companion. Follow the normal Android storage and Allow from this source prompts,
then Continue. Keep Android connected/unlocked and the companion foreground.
Access is tested before installing the game. If the firmware blocks both routes,
the beta stops clearly. No root, bootloader unlocking, custom firmware, arbitrary
permission grants or manual file-manager workaround. The companion may be removed
or its permissions revoked afterward. The Windows beta launcher is unsigned;
the included companion is signed independently of all Apple tooling.

Failure safety:
Existing KHUX installations and game content are refused for replacement. The
beta never uninstalls the game, clears saves or overwrites existing content.
It creates/removes only its own small access probes and writes new game files;
partial transfers are preserved. It does not auto-retry over a partial/existing
installation. Export a report if a transfer fails and request help rather than
deleting saves. Re:Awaken replaces no user data, so no replacement backup is
needed. Newer firmware restrictions, USB drivers, backgrounding, disconnects and
failure recovery remain beta testing areas. No Android Save Editor is included.

Feedback:
Click Export Beta Report after success or failure, review the JSON, and attach it
to https://github.com/qqCLUTCHYqq/reawaken-android/issues
Include device model + Android version + success/failure + steps to reproduce.
Reports contain the beta/Windows/Android versions, manufacturer/model/API/ABI,
ADB status, package/version, install/content/hash/launch results and fixed error
codes derived from ADB and game logcat. They contain no serials, passwords,
credentials, personal file paths, raw logs, game bytes or saves. Crash-buffer
classifications may describe a recent package crash rather than the current run.
Reports are exported locally; nothing is automatically uploaded.
Only attach the exported beta-report JSON. Do not share runtime-cache: it holds
your private staging files and local unfiltered troubleshooting logs.
