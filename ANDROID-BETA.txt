### Requirements and start

- Windows 10/11 x64 PC with .NET Framework 4.8
- Android device supporting ARM64 or ARMv7 native libraries
- USB data cable
- USB debugging enabled and the computer authorization prompt accepted
- **User-owned compatible KHUX + Dark Road 5.0.1 WW XAPK**
- PC internet for legitimate ADB tooling and acceptance of Google SDK terms

Download **ReAwaken-Android-Beta-2-Windows-x64.zip**, extract it into a writable folder, and open **ReAwaken-Android-Beta.exe**. Enable Developer Options by tapping Build number seven times; enable USB debugging and accept this computer. Select your XAPK and install. Re:Awaken validates the unchanged original APK/main.76/patch.87, installs, transfers both OBBs, verifies hashes, and launches the game. A verified official Node runtime and upstream license are included; Google ADB is obtained automatically. Allow about 2.3 GB of PC staging space plus your XAPK/tools, and about 3 GB free on Android.

If firmware restricts direct ADB OBB access, follow the companion’s normal storage and Allow from this source prompts, then Continue. Keep it foreground and Android connected/unlocked. Access is probed before game installation; if both routes fail, the beta stops clearly. Android 11 is proven; Android 8+ is a conditional declared range, with other Android versions/OEM firmware/AYN Thor untested. Only the primary Android user is supported.

**No game APK, XAPK, OBB, saves or copyrighted game content is included or downloaded. No root, bootloader unlocking, custom firmware, file-manager hacks, game patches or game re-signing.** Existing game installations/content are preserved and refused for replacement. Partial game-content files are retained on installation failure; game replacement/updates are deferred. The separate desktop updater never changes the game installation. No Android Save Editor or controller mapping is included. The Windows launcher is unsigned; the companion is separately signed.

### Tester feedback

Click **Export Beta Report**, review the JSON, then attach it to [GitHub Issues](https://github.com/qqCLUTCHYqq/reawaken-android/issues). Report **device model + Android version + success/failure + exported report**, and steps to reproduce. AYN Thor and other Android handheld testers are welcome.

The report contains beta/Windows/Android versions, manufacturer/model/API/ABI, ADB status, package/version, APK/content/hash/launch results and fixed sanitized error codes from ADB/game logcat. No serials, personal paths, passwords, credentials, raw logs, game bytes or saves. Nothing is automatically uploaded. Do not attach runtime-cache or game/save files; cache holds private staging and unfiltered local logs. Recent crash-buffer codes may precede the current attempt.
